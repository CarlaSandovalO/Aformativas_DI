 ¿Puede distinguir un resultado, una evidencia y una instrucción útil para auditar con IA?
Arrastre cada tarjeta a la columna que corresponda. Pista: pregúntese si el texto describe lo que se espera lograr, lo que permitirá demostrarlo o lo que le pediría a la IA para revisar la propuesta.
Tarjetas para arrastrar
Coloque cada tarjeta en una de estas tres categorías: Resultado, Evidencia o Auditar con IA.
Analizar alternativas para resolver un conflicto laboral y justificar la decisión más adecuada según el contexto.
Análisis de un caso con comparación de alternativas y justificación de una decisión.
Revisa si esta evidencia realmente permite demostrar el resultado esperado y señala posibles desajustes.
Elaborar una recomendación de mejora a partir del análisis de una situación de desempeño.
Entrega de una recomendación argumentada basada en la situación analizada y en criterios definidos.
Identifica supuestos, vacíos de información y aspectos del contexto que deberían revisarse antes de aceptar esta propuesta.
Resultado
¿Qué debe ser capaz de hacer el participante?
Arrastre aquí las tarjetas que describen el aprendizaje o desempeño esperado.
Evidencia
¿Qué permitirá demostrar ese aprendizaje?
Arrastre aquí las tarjetas que describen el producto, desempeño o evidencia.
Auditar con IA
¿Qué instrucción le daría a la IA para revisar?
Arrastre aquí las tarjetas que funcionan como instrucción para revisar o auditar.
Idea clave: primero defina el resultado, luego identifique la evidencia y después utilice la IA para revisar si ambas realmente guardan coherencia.
